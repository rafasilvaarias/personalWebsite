# Why

#logicChain Media advances change playback; The web has unique playback features; Streaming platforms ignore it; We should explore them instead.

Music media has always added playback features. Vinyl to CD added precise time-skipping, next and previous track controls, embedded metadata, and furthered the use of [hidden tracks](https://en.wikipedia.org/wiki/Hidden_track).
The web is an unique medium. It executes code. Accessible in any device with a browser (which is almost all modern devices).
Streaming platforms (like Spotify) ignore this. They just distribute static files. Yet [generative music has precedent](https://mitpress.mit.edu/9780262044912/the-computer-music-tutorial/), even in the [mainstream](https://generativemusic.com/bloom.html).
Conclusion -> explore how the web can run and distribute algorithmic music. See how building art for this medium changes the process, and its output.

# Project
The platform's design will follow expected interactions, or break them, whichever serves the artwork. 
The music is semi-stochastic. [Seeds](https://en.wikipedia.org/wiki/Pseudorandom_number_generator) make each playthrough replayable, but never identical. Macro parameters like project duration shift between plays. So do small things like a rhythmic fill, a melodic turn.
